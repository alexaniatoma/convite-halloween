# 🎃 Convite de Halloween

Um convite digital temático desenvolvido com **HTML5 e CSS3**, explorando elementos visuais inspirados no universo do Halloween para criar uma experiência interativa, sombria e envolvente.

## Sobre o projeto

O projeto consiste em uma página de convite digital para uma celebração de Halloween, com uma identidade visual temática e uma interface organizada para apresentar as informações do evento e permitir a interação do visitante por meio de um formulário.

O desenvolvimento teve como foco a estruturação semântica do HTML, a estilização com CSS e a construção de uma interface visualmente consistente.

##  Funcionalidades

- Página de convite com identidade visual temática.
- Formulário para interação e coleta de informações dos convidados.
- Footer personalizado com créditos e direitos autorais.
- Efeitos visuais e transições em elementos interativos.

## Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação e semântica da página |
| CSS3 | Estilização, layout e efeitos visuais |

## Conceitos aplicados

Durante o desenvolvimento, foram trabalhados:

- HTML semântico.
- Flexbox para organização e alinhamento dos elementos.
- CSS Variables para reutilização de valores visuais.
- Pseudo-classes e estados de interação.
- Transitions e efeitos de hover.
- Media Queries.
- Organização e reutilização de classes CSS.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd convite-hallowen
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um ambiente de execução.
